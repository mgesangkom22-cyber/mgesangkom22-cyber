### 🚀 Featured Projects

#### 1. Music Equipment Borrowing Monitoring System

A web-based music equipment borrowing and return monitoring system developed as my undergraduate thesis project at Universitas Nahdlatul Ulama Yogyakarta.

**Key Features:**

- Member registration and RFID-based identification.
- Music equipment identification using barcodes.
- Borrowing and return transaction management.
- Admin dashboard and inventory monitoring.
- Violation and fine management.
- Integration between Laravel API and ESP32.

**Technologies:** PHP, Laravel, MySQL, JavaScript, ESP32, RFID RC522.

🔗 [View Repository – Studio Musik](https://github.com/mgesangkom22-cyber/studio-musik)

#### 2. KASIRUANG – Coffee Shop Website

A website developed for KASIRUANG, a coffee shop in Yogyakarta, to provide business information and showcase its products and menu.

**Key Features:**

- Coffee shop landing page.
- Product menu and category display.
- Business information and location.
- Responsive website design.

**Technologies:** HTML, CSS, JavaScript.

🔗 [View Live Website](https://kasiruang-web.vercel.app/)
